# 📈 Stock Market Intelligence System

## Overview

The Stock Market Intelligence System is an end-to-end Data Analytics and Artificial Intelligence project that predicts the next-day movement of stock prices using historical stock market data and financial news.

The project includes data collection, preprocessing, exploratory data analysis, feature engineering, machine learning model building, business metric evaluation, and an interactive Streamlit web application.

---

## Features

- Historical stock data collection using Yahoo Finance
- Financial news collection using NewsAPI
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Random Forest Classification Model
- Business Metrics Evaluation
- Interactive Streamlit Dashboard
- Comparison of multiple assets
